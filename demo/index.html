Static frame — animated:false + renderStill(time)

t = 0.00s

A non-animated orb renders exactly one deterministic frame for the requested shader clock. Try it in a WebGL2 browser; without WebGL2 the Canvas2D fallback renders its own frame.

Full roster — all 66 styles, seven families

Each tile is one deterministic still — rendered sequentially through a single shared WebGL2 context, so the roster costs no running animation loops and no context budget.

Snippets

new Murmur(el, { style: "aura", tone: "#6c5ce7", state: "thinking" })
  .setSignals({ level: 0.6, activity: 0.4 });      // live voice + cadence
  .setTilt(0.2, -0.1);                              // glass parallax
  .setState("success");                             // entry: swell
  .setConfig({ style: "gather", ink: "#0a0a0f" });  // swap style, keep dials
  .renderStill(4.0);                                // one deterministic frame
  .destroy();
